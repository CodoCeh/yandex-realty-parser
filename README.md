# Yandex Realty Parser

Закрытый компонент CodoCeh для получения и нормализации рыночных данных из объявлений Яндекс.Недвижимости.

Репозиторий служит только витриной существования продукта. Исходный код, конфигурация, данные и рабочие сборки не публикуются.

Для партнёрства или демонстрации — свяжитесь с командой CodoCeh.
